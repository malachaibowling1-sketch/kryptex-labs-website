# Kryptex Labs Website

A complete responsive static storefront/landing page with the dark neon-green Kryptex Labs aesthetic.

## Included
- Home / hero
- Store / product cards
- Games section
- Discord support section
- About section
- Responsive mobile layout
- Login/Register placeholder modal
- Checkout-ready product buttons
- Green Kryptex Labs logo SVG
- Green hero/banner artwork

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the contents of this folder to a static host such as GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## Connect real services
The UI is complete, but real accounts and payments require a backend/payment provider. The buttons are intentionally placeholders until you connect your own services.

## Branding
Replace `assets/kryptex-green-banner.png` with your final banner artwork if desired. `assets/logo.svg` can be used as the Discord/server logo.
